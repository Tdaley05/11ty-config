### Want to Start Your Own Collection?

On my own, I don't have the biggest collection yet, which is by no means a bad thing. We all have to start somewhere.

I sometimes look atother <a href="https://kdkemp.com/pmg">physical media collection guides like this</a>  because it's always good to get a second opinion to aviod getting media that is broken, will break, or is better left for someone else. Not to mention mold or magnetized media, which is extremely important to be aware of.

Honestly, that guide has a lot to it as well as even more resources. I come back to it a lot as a reference point.
